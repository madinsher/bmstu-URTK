# Комплект курса «Управление робототехническими комплексами» (УРТК)

Редакция 2026.

## Что это

Учебно-методический комплект магистерского курса: **17 лекций, 8 семинаров, домашнее задание**.

Предмет курса — проектирование управления сложным робототехническим комплексом: мобильный манипулятор, автономно выполняющий сбор и доставку объектов, либо производственная линия с разнотипным оборудованием и несколькими промышленными манипуляторами.

Курс не повторяет конечные автоматы и сети Петри, пройденные на 3-м курсе. Он строит поверх них слой, которым проектируют комплексы: синтез логики по спецификации, структурный анализ ресурсных конфликтов, верификация, планирование задач, координация нескольких роботов, реальное время, надёжность и приёмка.

Практика — в виртуальной среде **Webots**. Разработка программного обеспечения для реального оборудования — предмет отдельного курса «Программное обеспечение управляющих комплексов» (ПОУК); настоящий курс с ним не пересекается.

## Сквозные примеры

Весь материал проходит через два примера:

- **А — мобильный манипулятор-сборщик** (Webots youBot): неопределённость, восприятие, TAMP;
- **Б — производственная ячейка** (2 манипулятора, станок, буфер, AMR, общая зона): параллелизм, ресурсы, тупики, производительность.

Команда выбирает один из них на семинаре 1 и ведёт до защиты.

## Инструменты, используемые на семинарах

| Тема | Инструмент |
|---|---|
| Дискретно-событийные системы | Supremica, собственная реализация на Python |
| Сети Петри | PIPE, собственный поиск сифонов |
| Производительность | SimPy, max-plus (алгоритм Карпа) |
| Исполнительная логика | py_trees, BehaviorTree.CPP, SMACH (для сравнения) |
| Верификация | NuSMV / nuXmv, UPPAAL |
| Синтез | Slugs, TuLiP |
| Планирование | Fast Downward, pyperplan, OPTIC |
| Решения при неопределённости | pomdp-py, POMDPs.jl, PRISM |
| Расписание | OR-Tools CP-SAT |
| Поиск отказов | RTAMT, S-TaLiRo |
| Среда | Webots |

Все инструменты бесплатны и доступны для установки студентами.
